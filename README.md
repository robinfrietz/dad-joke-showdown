One line: a dad joke fit for the dinner table, punchline at the end.

> I named my dog Stay. Now when I call him, he stays.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Files

- `main.ts` — writes the dad joke to `/output/entry.txt`, deterministic, no network.
